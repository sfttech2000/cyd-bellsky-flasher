Bell Sky Patrol 1.0.0 - คู่มือการเล่น
เกมยิงแนวตั้งบนบอร์ด CYD (ESP32-2432S028R) จอ 2.8 นิ้ว · by tee & claude

ถือบอร์ดแนวตั้ง ให้สาย USB อยู่ด้านล่าง

== เปิดครั้งแรก ==
แตะกลางกากบาท + ให้ครบ 4 มุม แล้วแตะกล่อง OK สีเขียว (ทำครั้งเดียว)
ปรับทัชใหม่: กดปุ่ม BOOT ค้าง 2 วินาทีที่หน้าปก

== วิธีเล่นด้วยนิ้ว ==
- วางนิ้วตรงไหนของจอก็ได้แล้วลาก ยานจะขยับตามระยะที่นิ้วเลื่อน นิ้วจึงไม่บังยาน
- ระหว่างนิ้วแตะจอ ยานจะยิงขึ้นฟ้าและทิ้งระเบิดลงพื้นเอง
- ปุ่ม BOMB มุมขวาล่าง: แตะเพื่อล้างกระสุนศัตรูทั้งจอ (ชีวิตละ 3 ลูก)
- ยกนิ้วออกเกิน 2 วินาที เกมจะหยุดรอ แตะจอเพื่อเล่นต่อ

== วิธีเล่นด้วยจอยบลูทูธ ==
ใช้จอยแบบ BLE เช่น ShanWan Q36 (กด L + X + Home ค้างจนไฟกะพริบ บอร์ดจะหาจอยเอง)
- ลูกศร / ก้านซ้าย: บังคับยาน (ยิงเองตลอด)
- A หรือ B: ระเบิดล้างจอ
- +: หยุด / เล่นต่อ
- หน้าปก: ซ้าย / ขวา เลือกยาน, A เริ่มเกม

== กระดิ่ง ==
ยิงเมฆให้กระดิ่งหล่นออกมา กระดิ่งที่อยู่ไกล ยิงโดน 4 นัดจะเปลี่ยนสี
บินเข้าไปหากระดิ่งเพื่อเก็บ กระดิ่งที่อยู่ใกล้ยาน กระสุนจะทะลุผ่านและกระดิ่งจะลอยเข้าหายานเอง
- เหลือง: คะแนน เก็บต่อเนื่องยิ่งได้มาก (ปล่อยกระดิ่งเหลืองตกจอ จะเริ่มนับใหม่)
- ฟ้า: ยิงเร็วขึ้น (5 ขั้น)
- ขาว: ยิงคู่
- เขียว: ยานผู้ช่วย (2 ลำ)
- แดง: เกราะ กันโดนได้ 5 ครั้ง

== ด่าน ==
มี 3 ด่าน: ชนบท, ทะเล, กลางคืน ด่านละประมาณ 100 วินาที แล้วเจอบอส
บอสมี 2 ร่าง: ยิงป้อมสองข้างให้พังก่อน แล้วยิงแกนกลาง
ศัตรูบนพื้นโดนเฉพาะระเบิดที่ยานทิ้งเอง
ผ่านครบ 3 ด่านแล้ววนรอบใหม่ที่ยากขึ้น เล่นไปจนชีวิตหมด (เริ่มด้วย 5 ชีวิต)

== ยาน ==
กระดิ่งที่เก็บได้ทุกเกมจะสะสมไว้ แม้รอบนั้นแพ้ก็ยังนับ แตะยานที่หน้าปกเพื่อเลือก
- SKY: ยานเริ่มต้น
- RUBY (100 ลูก): เริ่มด้วยยิงคู่
- LEAF (300 ลูก): เริ่มด้วยยานผู้ช่วย
- GOLD (600 ลูก): เริ่มด้วยยิงคู่และยิงเร็ว 2 ขั้น

== เซฟ ==
คะแนน 5 อันดับ กระดิ่ง และยาน เก็บในบอร์ด อัปเดตเกมจากหน้าติดตั้งแล้วเซฟไม่หาย
ก่อนเอาบอร์ดไปลงโปรแกรมอื่น กด "เก็บเซฟเป็นไฟล์" ที่หน้าติดตั้งไว้ก่อน
ไฟล์เซฟใช้ได้กับบอร์ดตัวเดิมเท่านั้น

== เสียง ==
ออกทางลำโพงที่ต่อกับบอร์ด บอร์ดส่วนใหญ่ไม่มีลำโพงมาให้ ไม่มีเสียงก็เล่นได้ปกติ
